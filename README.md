## Assignments

| Folder | What it does |
|--------|-------------|
| `Assignment1-SquareMatrixAnalyzer` | Takes a square matrix as input and prints row sums, column sums, and both diagonal sums |
| `Assignment2-MagicSquare` | Reads a matrix and checks whether it's a magic square by comparing all row, column, and diagonal sums |
| `Assignment3-HammingCode` | Marks parity bit positions (powers of 2) as h1, h2, h3... and the rest as data bits |
| `Assignment4-MagicSquareChecker` | Same magic square logic but structured with a separate function |
| `Assignment5-ModularExponentiation` | Computes base^exp mod n using the fast binary exponentiation method (used in RSA) |
| `Assignment6-Functions` | Six tasks in one file using functions: sum/average, student result with CGPA, matrix addition, factorial, prime check, hamming positions |
| `Assignment6-MatrixOperations` | Matrix addition, subtraction, multiplication, transpose, diagonal sums and element sum |
| `Assignment6-FileHandling` | Reads a countries CSV file and calculates population density for each country |
| `Assignment8-SalesReport` | Four parts: product-wise and rep ID-wise sales totals, each done with Arrays and then with HashMap |
| `Assignment9-DecimalToBinary` | Converts a decimal number to binary using manual division |

```bash
javac Assignment5_ModularExp.java

```

For Assignment 6 FileHandling and Assignment 8, you'll need to set the correct path to your `.txt` data file inside the code before running.
